# Evidencias de Pruebas — Aura Eventos

Este directorio contiene los registros de ejecución y evidencias visuales para las pruebas realizadas en el emulador (Release APK `app-release.apk`).

- `CP-01_login_cliente.txt`: Registro de inicio de sesión exitoso con cuenta cliente demo `maria@gmail.com`.
- `CP-02_login_admin.txt`: Registro de inicio de sesión exitoso con cuenta administradora demo `ana@aura.com`.
- `CP-14_conflicto_calendario.txt`: Validación del bloqueo de fechas sin disponibilidad (días en gris 1-21).
- `CP-18_solicitudes_pendientes.txt`: Visualización del listado de solicitudes en estado `PENDIENTE`.
- `CP-21_nota_remision_pdf.txt`: Generación y apertura de la Nota de Remisión en PDF nativo (`nota-AUR-2026-0801.pdf`).
- `CP-25_photo_picker.txt`: Invocación del componente oficial `com.google.android.photopicker`.
